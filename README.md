🎮 Arcade POO

Proyecto desarrollado para la materia Programación Orientada a Objetos (POO). La aplicación reúne tres videojuegos clásicos implementados en Java: Pong, Space Invaders y Lode Runner. Cada juego cuenta con un menú de configuración propio que permite personalizar distintos aspectos visuales y sonoros antes de iniciar la partida, brindando una experiencia más dinámica y adaptable para el usuario.

📋 Características Generales
Menú principal para acceder a los distintos juegos.

- Menús de configuración independientes para cada videojuego.
- Personalización de sprites, escenarios y sonidos.
- Aplicación desarrollada aplicando conceptos de Programación Orientada a Objetos.
- Organización modular del código para facilitar el mantenimiento y futuras ampliaciones.
🏓 Pong

Esta versión del clásico juego de tenis de mesa permite personalizar múltiples elementos antes de jugar. El usuario puede seleccionar entre la cancha original y dos diseños alternativos, elegir entre la paleta original y dos variantes adicionales, y cambiar la apariencia de la pelota utilizando dos skins extra además de la predeterminada. También es posible modificar la música de fondo mediante las opciones disponibles en el menú de configuración.

👾 Space Invaders

La adaptación del clásico Space Invaders incorpora opciones de personalización para los invasores, permitiendo elegir entre la apariencia original y dos skins alternativas. Asimismo, el fondo del juego puede modificarse entre el diseño predeterminado y dos variantes adicionales. El menú de configuración también ofrece la posibilidad de cambiar la música de fondo para adaptar la experiencia de juego a las preferencias del usuario.

🏃 Lode Runner

La versión de Lode Runner incluye opciones de personalización más simples, permitiendo cambiar la apariencia principal del juego mediante una skin alternativa además de la original. También es posible seleccionar entre diferentes sonidos o efectos de audio disponibles desde el menú de configuración.

🛠️ Tecnologías Utilizadas
Java
- Swing/AWT para la interfaz gráfica
- Programación Orientada a Objetos
- Manejo de imágenes y recursos multimedia
- Gestión de sonido mediante archivos de audio
🎯 Objetivos del Proyecto

El objetivo principal de este proyecto fue aplicar los conceptos fundamentales de la Programación Orientada a Objetos en el desarrollo de una aplicación interactiva. Para ello se utilizaron principios como encapsulamiento, herencia, polimorfismo y abstracción, además de técnicas de reutilización de código y diseño modular. El proyecto también permitió adquirir experiencia en el desarrollo de interfaces gráficas y en la gestión de recursos multimedia dentro de aplicaciones Java.

🚀 Ejecución
1. Descargar o clonar el repositorio.
2. Abrir el proyecto en un entorno de desarrollo compatible con Java.
3. Compilar el proyecto.
4. Ejecutar la clase principal del lanzador.
5. Seleccionar el juego deseado desde el menú principal y configurar sus opciones antes de comenzar la partida.
